# Быстрый старт

## 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 2. Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен
2. Создайте канал для уведомлений (или используйте существующий)
3. Добавьте бота в канал как администратора
4. Получите ID канала (можно использовать [@userinfobot](https://t.me/userinfobot) или [@getidsbot](https://t.me/getidsbot))
5. Получите свой ID (также через @userinfobot)

## 3. Создание файла .env

Скопируйте `env_example.txt` в `.env` и заполните:

```env
BOT_TOKEN=ваш_токен_от_BotFather
NOTIFICATION_CHANNEL_ID=@ваш_канал или числовой_ID
ADMIN_IDS=ваш_telegram_id
```

## 4. Запуск

```bash
python bot.py
```

## 5. Проверка работы

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Попробуйте оставить отзыв через кнопки или команды
4. Проверьте админ-панель командой `/admin` (только для админов)

## Важные замечания

- Убедитесь, что бот добавлен в канал как администратор
- ID канала можно указать как `@channel_username` или числовой ID (например, `-1001234567890`)
- Для получения числового ID канала можно использовать бота [@getidsbot](https://t.me/getidsbot)
- База данных создается автоматически при первом запуске
