# Telegram бот для сбора обратной связи о мобильном приложении

Telegram бот на Python для сбора обратной связи о мобильном приложении колледжа с использованием библиотеки `python-telegram-bot`.

## 🚀 Возможности

- ✅ Система команд (`/start`, `/feedback`, `/bug`, `/idea`, `/help`)
- ✅ Интерактивные кнопки для удобной навигации
- ✅ Сбор детальной информации о багах, идеях и отзывах
- ✅ Хранение данных в SQLite базе данных
- ✅ Админ-панель с управлением отзывами
- ✅ Автоматические уведомления в канал
- ✅ Система приоритетов для багов
- ✅ Напоминания о необработанных отзывах
- ✅ Экспорт данных в CSV
- ✅ Статистика и аналитика

## 📋 Требования

- Python 3.8+
- python-telegram-bot ^20.0
- SQLite3 (встроен в Python)

## 🔧 Установка

1. Клонируйте репозиторий или скачайте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env` файл:
   - Получите токен бота у [@BotFather](https://t.me/BotFather)
   - Создайте канал для уведомлений и добавьте бота как администратора
   - Получите ID канала (можно использовать бота [@userinfobot](https://t.me/userinfobot))
   - Укажите ID админов (можно получить у [@userinfobot](https://t.me/userinfobot))

## 🎯 Использование

### Локальный запуск:
```bash
python bot.py
```

### Развертывание на бесплатном сервере:
См. файлы:
- `FREE_DEPLOY.md` - обзор бесплатных платформ
- `RAILWAY_DEPLOY.md` - развертывание на Railway.app (рекомендуется)
- `RENDER_DEPLOY.md` - развертывание на Render.com

## 📱 Команды бота

### Для пользователей:
- `/start` - приветствие и инструкция
- `/feedback` - оставить общий отзыв
- `/bug` - сообщить об ошибке
- `/idea` - предложить идею
- `/help` - помощь по командам

### Для админов:
- `/admin` - админ-панель со статистикой и управлением отзывами

## 🗄️ Структура базы данных

База данных автоматически создается при первом запуске. Таблица `feedback` содержит:
- Информацию о пользователе
- Тип фидбека (bug/idea/feedback)
- Описание и детали
- Приоритет и статус
- Даты создания и обновления

## 📊 Админ-панель

Админ-панель предоставляет:
- Просмотр всех отзывов с фильтрацией
- Изменение статусов (new/in_progress/resolved)
- Статистику по типам фидбека
- Экспорт данных в CSV
- Просмотр необработанных отзывов

## 🔔 Уведомления

Бот автоматически отправляет уведомления о новых фидбеках в настроенный канал. Также есть система напоминаний о необработанных отзывах.

## 📝 Логирование

Все события логируются в файл `bot.log` и выводятся в консоль.
