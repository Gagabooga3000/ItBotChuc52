# 🚂 Развертывание на Railway.app (БЕСПЛАТНО)

Railway.app предоставляет бесплатный тариф с $5 кредитами каждый месяц, чего более чем достаточно для Telegram бота.

## 📋 Шаг 1: Подготовка проекта

1. Убедитесь, что у вас есть файл `requirements.txt`
2. Убедитесь, что файл `.env` НЕ закоммичен в Git (должен быть в `.gitignore`)

## 🚀 Шаг 2: Регистрация на Railway

1. Перейдите на [railway.app](https://railway.app)
2. Нажмите "Start a New Project"
3. Войдите через GitHub (рекомендуется) или Email

## 📦 Шаг 3: Создание проекта

### Вариант A: Через GitHub (рекомендуется)

1. Нажмите "Deploy from GitHub repo"
2. Выберите ваш репозиторий с ботом
3. Railway автоматически определит Python проект

### Вариант B: Через Railway CLI

1. Установите Railway CLI:
   ```bash
   npm i -g @railway/cli
   ```

2. Войдите:
   ```bash
   railway login
   ```

3. Инициализируйте проект:
   ```bash
   railway init
   ```

4. Загрузите файлы:
   ```bash
   railway up
   ```

## ⚙️ Шаг 4: Настройка переменных окружения

1. В проекте Railway нажмите на ваш сервис
2. Перейдите в раздел "Variables"
3. Добавьте переменные:

   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   NOTIFICATION_CHANNEL_ID=ваш_channel_id
   ADMIN_IDS=1027500941
   ```

4. Нажмите "Add" для каждой переменной

## 🔧 Шаг 5: Настройка запуска

1. Перейдите в раздел "Settings"
2. В поле "Start Command" укажите:
   ```
   python bot.py
   ```

3. Railway автоматически определит Python и установит зависимости из `requirements.txt`

## ✅ Шаг 6: Деплой

1. Railway автоматически запустит бота после настройки
2. Проверьте логи в разделе "Deployments" → выберите последний деплой → "View Logs"
3. Вы должны увидеть: `Бот запущен`

## 🔍 Проверка работы

1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте команду `/start`
4. Бот должен ответить!

## 📊 Мониторинг

- **Логи:** Раздел "Deployments" → выберите деплой → "View Logs"
- **Метрики:** Раздел "Metrics" показывает использование ресурсов
- **Переменные:** Раздел "Variables" для изменения настроек

## 🔄 Обновление бота

Если вы используете GitHub:
- Просто сделайте `git push` в ваш репозиторий
- Railway автоматически перезапустит бота

Если используете CLI:
```bash
railway up
```

## 💡 Полезные команды Railway CLI

```bash
# Просмотр логов
railway logs

# Просмотр переменных
railway variables

# Добавление переменной
railway variables set BOT_TOKEN=ваш_токен

# Перезапуск сервиса
railway restart
```

## ⚠️ Важные замечания

1. **Бесплатный тариф:** $5 кредитов в месяц (достаточно для бота)
2. **Автоспящий режим:** После 5 минут бездействия сервис может "заснуть", но автоматически проснется при первом запросе
3. **База данных:** SQLite файл будет храниться в файловой системе Railway (сохраняется между деплоями)
4. **Логи:** Хранятся только последние 1000 строк

## 🆘 Решение проблем

### Бот не запускается
- Проверьте логи в Railway
- Убедитесь, что все переменные окружения установлены
- Проверьте, что `requirements.txt` содержит все зависимости

### Ошибка "BOT_TOKEN не установлен"
- Проверьте раздел "Variables" в Railway
- Убедитесь, что переменная называется именно `BOT_TOKEN`

### Бот не отвечает
- Проверьте логи на наличие ошибок
- Убедитесь, что токен бота правильный
- Проверьте, что бот не заблокирован в Telegram
