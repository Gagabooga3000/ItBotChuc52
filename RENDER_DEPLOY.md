# 🎨 Развертывание на Render.com (БЕСПЛАТНО)

Render.com предоставляет бесплатный тариф для веб-сервисов с некоторыми ограничениями.

## 📋 Шаг 1: Подготовка

1. Убедитесь, что у вас есть файл `requirements.txt`
2. Создайте файл `Procfile` (опционально, но рекомендуется)

## 📝 Создание Procfile

Создайте файл `Procfile` в корне проекта:
```
worker: python bot.py
```

## 🚀 Шаг 2: Регистрация

1. Перейдите на [render.com](https://render.com)
2. Нажмите "Get Started for Free"
3. Войдите через GitHub (рекомендуется)

## 📦 Шаг 3: Создание Web Service

1. Нажмите "New +" → "Web Service"
2. Подключите ваш GitHub репозиторий
3. Или используйте "Public Git repository" и укажите URL

## ⚙️ Шаг 4: Настройка

Заполните форму:

- **Name:** `telegram-feedback-bot` (или любое имя)
- **Environment:** `Python 3`
- **Region:** Выберите ближайший (например, Frankfurt)
- **Branch:** `main` (или ваша основная ветка)
- **Root Directory:** оставьте пустым
- **Build Command:** 
  ```
  pip install -r requirements.txt
  ```
- **Start Command:**
  ```
  python bot.py
  ```

## 🔐 Шаг 5: Переменные окружения

1. Прокрутите вниз до раздела "Environment Variables"
2. Нажмите "Add Environment Variable"
3. Добавьте переменные:

   ```
   BOT_TOKEN = ваш_токен_от_BotFather
   NOTIFICATION_CHANNEL_ID = ваш_channel_id
   ADMIN_IDS = 1027500941
   ```

4. Нажмите "Create Web Service"

## ⏱️ Шаг 6: Ожидание деплоя

1. Render начнет сборку проекта (займет 2-5 минут)
2. Следите за логами в реальном времени
3. После успешного деплоя вы увидите "Your service is live"

## ✅ Проверка работы

1. Откройте раздел "Logs" в Render
2. Вы должны увидеть: `Бот запущен`
3. Проверьте бота в Telegram командой `/start`

## ⚠️ Важные замечания

1. **Автоспящий режим:** Бесплатные сервисы "засыпают" после 15 минут бездействия
   - Первый запрос может занять 30-60 секунд для "пробуждения"
   - Для Telegram бота это не критично, так как бот сам делает запросы к API

2. **Ограничения бесплатного тарифа:**
   - 750 часов работы в месяц (достаточно для 24/7)
   - Автоматическое пробуждение при запросах

3. **База данных:** SQLite файл хранится в файловой системе (сохраняется между деплоями)

## 🔄 Обновление

1. Сделайте `git push` в ваш репозиторий
2. Render автоматически обнаружит изменения и перезапустит сервис

## 🆘 Решение проблем

### Сервис не запускается
- Проверьте логи в разделе "Logs"
- Убедитесь, что Start Command правильный: `python bot.py`

### Бот не отвечает
- Проверьте, что все переменные окружения установлены
- Убедитесь, что токен бота правильный
- Проверьте логи на наличие ошибок

### Сервис "спит"
- Это нормально для бесплатного тарифа
- Бот автоматически "проснется" при первом обновлении от Telegram

## 📊 Мониторинг

- **Логи:** Раздел "Logs" показывает все выводы бота
- **Метрики:** Раздел "Metrics" показывает использование ресурсов
- **События:** Раздел "Events" показывает историю деплоев

## 💡 Альтернатива: Background Worker

Вместо Web Service можно создать Background Worker:

1. "New +" → "Background Worker"
2. Те же настройки, что и для Web Service
3. Background Worker не имеет автоспящего режима (но может быть ограничен по времени работы)
